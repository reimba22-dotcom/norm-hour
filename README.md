# M-Telemetry 2.0 — Нормо-часы для автомехаников

Современное PWA-приложение для учета заказ-нарядов, нормо-часов, выработки и AW (*Arbeitswerte*) в стиле BMW M-Cockpit.

## ✨ Основные возможности (v2.0)
- 🎨 **Новый дизайн 2.0**: Кокпит в стиле премиальных автомобильных интерфейсов, новейшая темная и светлая темы, M-Shift индикатор нагрузки.
- 💾 **Хранилище IndexedDB**: Фотографии документов и нарядов высокого разрешения сохраняются локально без ограничений памяти (снят 5 МБ лимит `localStorage`).
- ⚡ **Офлайн PWA**: Полная автономная работа в подземных паркингах и экранированных ремзонах через Service Worker.
- ⏱️ **Быстрые пресеты ТО**: Добавление частых работ (масло, колодки, сход-развал) в один тап.
- 📷 **OCR распознавание**: Сканирование бланков и номеров заказ-нарядов с камеры и из галереи.
- 📅 **График смен**: Автогенерация смен (`РРВВ`, 2/2, 3/3, 5/2) и расчет зарплаты с окладом.
- 📊 **Телеметрия и экспорт**: Аналитика по среднему чеку, темпу AW и выгрузка в CSV/JSON.

## 🚀 Быстрый запуск
Открыть `index.html` в любом современном браузере или запустить локальный сервер:
```bash
node server.js
```
Адрес: `http://127.0.0.1:8085`
